# 强度测评中心：测评标准与局限

方法版本：1.0（2026-10-21）。标准档证据采集于 2026-10-20。此文可随天梯报告发布，供玩家审阅和提出修正。

## 发布时请一起说明

本天梯衡量**固定靶场中的原生自动能力**，适合比较插件与游戏自带单位的基础表现。英雄近战和远程分别测量，保留自动技能、反击及召唤物；另外记录普攻动作、弹丸、命中和有效伤害证据。输出、守线、辅助是三张不同用途的天梯，不合成一个“实战总强度”。

标准档覆盖 79 位英雄室可选英雄的 158 个近远程条目，以及 103 座常规塔（91 座最终阶级、12 座过渡阶级），共 15,145 个成功轮次，正式样本无失败。另测 6 个原生特殊／备用英雄和 18 座关卡特殊塔，单独列附录。杜拉克斯分身作为召唤物，不作独立英雄参照。

标准档总计尝试 16,855 轮，其中附录有 320 个失败轮次。失败对象不生成等级；不能将“未评测”理解为弱，也不能将没有对应普攻的模式理解为具有该类普攻。快速档单独运行 30 秒 × 3 种子，不能直接与标准档等级混排。

目前没有完整复现手动大招、关卡专属机关、真实波次、复杂地形和玩家操作；天梯需要专业玩家提供反例与遗漏机制，尚不能替代实战评价。

## 运行条件与样本

使用游戏自带 LÖVE 引擎，按固定 `1/30` 秒推进原生 simulation 与 render_update。后台模式省略窗口绘制和现实时间等待，保留攻击动画时序、弹丸、原生 AI、冷却、命中、伤害回调和召唤物。

后台工具只初始化强度测评中心，使用隔离的存档身份、默认配置，不加载其他插件。等级固定为普通，关闭科技和道具，不写入玩家战役进度。游戏内手动运行的测评另记当时配置，不能视为后台隔离原生条件。

| 档位 | 单场时间 | 重复 | 种子 |
|---|---:|---:|---|
| 快速 | 30 秒 | 3 | 1729、7919、104729 |
| 标准 | 60 秒 | 5 | 1729、7919、104729、65537、99991 |
| 长时（游戏内） | 180 秒；机动最多 60 秒 | 5 | 同标准 |

当前完整原生参照针对快速、标准两档分别生成；长时档仍是较小的既有实测参照，不宣称全量校准。每轮重置模板、实体和随机种子，重新开始原生冷却及入场过程。固定种子有助于复现，但不同单位消耗随机数的次数不同，不能将相同种子视为完全相同的伤害序列。

英雄按原生升级函数逐级升至 10 级，记录实际技能等级；没有额外注入技能倍率。防御塔设为原生 powers 最高等级，原生雇佣塔按默认兵种自动满员、补员，记录雇佣费用。没有实现所有可选兵种、手动切换形态或手动技能的最优策略。

## 英雄近远程如何分开

1. 每英雄建立近战和远程两个独立条目，使用同一个英雄参照，允许比较两种站位的结果。
2. 仅禁用主体相反模式的第一个普攻槽；自动技能、反击、变形和召唤物保留。**这不是纯普攻伤害排名**。
3. 静止靶场中，远程主体站在近战索敌范围外，尽可能同时满足原生远程最小／最大射程，避免落在远程死区。近战主体使用统一位置。
4. 移动群体、守线及承伤场景保留统一站位，允许原生 AI 自行移动与交战。远程模式不保证始终保持理想射击距离。
5. 模板不存在对应普攻槽时标记“无对应主体普攻”；自动技能或召唤物仍可产生伤害，不能据此宣称该英雄拥有远程／近战普攻。
6. 普攻证据分为主体近战普攻、主体远程普攻、自动技能、召唤物及其他原生结算。艾瑞丹（`hero_elves_archer`）和范海辛（`hero_van_helsing`）的原生连射复用普攻弹丸，部分来源标签可能混合；总有效输出保留，不能将标签直接解释为纯普攻占比。

## 场景与标准靶

英雄每模式 12 个场景，塔 11 个场景（不测机动）。路径为平直单路，主体位置约 x=500、y=384；塔位 y=438；静止靶 x=532。移动目标从右侧分三条相邻子路径进入；离开 x<280 计漏怪并补充。死亡／被移除目标也会补充，因此统计的是持续供靶条件下的能力。

| 场景 ID | 条件 | 用途 |
|---|---|---|
| `single` | 1 个地面静止靶，3000 HP，双抗 0 | 对单 |
| `swarm` | 8 个移动地面靶，600 HP，双抗 0，速度 24 | 对群 |
| `air` | 1 个飞行静止靶，3000 HP | 单体对空 |
| `air_swarm` | 8 个移动飞行靶，600 HP，速度 24 | 群体对空 |
| `armor` | 1 个静止靶，3000 HP，物抗 80% | 高物抗输出 |
| `magic` | 1 个静止靶，3000 HP，魔抗 80% | 高魔抗输出 |
| `boss` | 1 个静止靶，30000 HP，沿用毁灭者的目标标志、禁效及秒杀抗性 | Boss 免疫适应性 |
| `control` | 8 个移动地面靶，10000 HP，速度 24 | 控场及拦截 |
| `survival` | 8 个移动敌人，600 HP，有攻击压力 | 主体存活 |
| `support_base` | 无被测对象；3 名 60% 血量步兵＋1 座一级箭塔；相同敌人 | 辅助对照 |
| `support` | 同上，加入被测对象 | 友军增益 |
| `mobility` | 无敌人，发送原生集结命令连续往返 | 机动 |

地面标准靶以原生哥布林为基础；飞行靶以石像鬼为基础，不代表所有敌人的体型、飞行高度、抗性、元素、闪避或特殊无敌阶段。承伤／辅助压力场景中，奇数目标为近战靶（18–24 伤害、1 秒攻击冷却），偶数目标改用原生暗影射手，以便飞行英雄也承受远程压力。射手保留原生远程攻击规则。

Boss 场景使用**标准靶 AI**，没有复制毁灭者关卡的行动和特殊技能。报告中的“攻坚”衡量抗性与免疫条件下的输出，不是完整 Boss 战胜率。

机动首段从 x=500 到 760，名义距离 260；随后在 760 与 240 之间往返，每段 520。进入目标 20 像素内且没有 pending 瞬移后才计为完成并发送下一段。计入入场、前后摇、变形、瞬移和冷却；不重置冷却，也不等待最优瞬移时机。未完成的末段不计距离，因此小样本存在阶梯误差。维兹南等瞬移英雄通过原生 `nav_rally.new` 指令触发，不能以步行速度代替测量。

## 原始指标的计算

先逐轮计算，再对有效轮次取算术均值。均值、最小值、最大值和离散程度用于描述固定种子的实测差异，不是总体置信区间。

| 维度 | 计算口径 |
|---|---|
| 对单 | `single` 的有效输出率 |
| 对群 | `swarm` 的有效输出率 |
| 对空 | `air` 与 `air_swarm` 有效输出率的等权平均 |
| 攻坚 | `armor`、`magic`、`boss` 有效输出率的等权平均 |
| 控场 | `control` 中控制等效目标秒 / 测量秒数；可超过 1 |
| 生存（英雄） | `max(0, 100 × 主体存活秒 / 测量秒数 − 5 × 主体死亡次数)` |
| 拦截（塔） | `control` 中被主体或归属召唤单位阻挡的目标秒 / 测量秒数 |
| 辅助 | 同种子配对下的友军输出增量比例、友军存活增量和治疗归一值之和，见下文 |
| 机动（英雄） | 已完成分段的名义距离总和 / 测量秒数 |
| 性价比（塔） | `(对单×.25 + 对群×.35 + 对空×.15 + 攻坚×.25 + 拦截×30) / (成本/1000)` |

有效输出率 = `(普通有效伤害 + 秒杀／吞噬实际消耗生命) / 时长`。普通 DPS 仅为普通有效伤害 / 时长，和评分所用输出率可能不同。伤害依据原生结算，在目标 on_damage 回调后读取扣血前生命，将 damage_applied 封顶到剩余生命，排除过量伤害。变羊／移除而没有可验证伤害时不补造伤害。主体、召唤物及反伤等按原生归属根汇总；缺少必要扣血快照的轮次撤回评分。

控制等效目标秒：眩晕按 1 倍时间，减速按 `1−当前速度/基础速度`（限制 0–1），后退超过两个路径节点按后退距离／基础速度折算（单次最多 10 秒）。这是估计量，可能受路径跳变或多重效果影响。幽灵墓地的附身单位离开敌人索引后，另按实际存活受控时间计入控制，并归属被控单位造成的伤害；旧版遗漏这部分的轮次不可直接补评。

辅助逐轮公式：

`max(0,(友军伤害−对照友军伤害)/max(1,对照友军伤害)) + max(0,(友军存活秒−对照友军存活秒)/(3×时长)) + 有效治疗/(30×时长)`。

该指标会将“先杀死敌人从而保护友军”计为辅助结果，并不等同于纯增益技能强度。固定步兵／箭塔队伍也不能覆盖所有增益对象和阵容。

塔成本按原生草地塔位升级菜单寻找最低建造升级路径，加上满级技能购买费用；没有标准升级链时回退到模板直接价格并注明。雇佣塔再加逐轮平均雇佣支出。计入金币，不计解锁时间、科技成本、塔位稀缺或玩家操作成本。输出天梯本身不做等预算配平，性价比单列。

## 固定参照、分数与天梯

英雄参照取全部 79 位可选英雄、两个模式共 158 条目的各轴**正值中位数**；塔参照只取 91 座常规最终阶级塔。过渡塔、关卡特殊塔和特殊英雄按同类参照显示，但不反过来改变正式参照。

每档独立：`轴分数 = min(100,70×sqrt(max(0,原始指标)/该轴固定参照))`。选择正值中位数是为了避免大量无对空／无控场／无治疗单位将参照压到零；它会让具有稀缺能力的单位与“具备该能力的原生样本”比较，而非与全体零值比较。请专业玩家重点审阅这一取舍。

| 评价 | 权重 |
|---|---|
| 输出 | 对单 25%＋对群 35%＋对空 15%＋攻坚 25% |
| 守线 | 生存（英雄）／拦截（塔）40%＋辅助 25%＋控场 35% |
| 辅助 | 辅助 70%＋控场 30% |

S≥90，A≥75，B≥60，C≥45，D≥25，E>0，0 为“无”。判级使用未四舍五入值，显示 75.0 但实际略低于 75 时仍可能为 B。封顶后同分按未封顶轴分加权值，再按模板 ID 排序；这只是稳定显示顺序，不是新的等级。缺失轴、失败轮次或环境不兼容显示“未评测”，不替换为零。

## 当前明确未覆盖／需要验证的地方

- **时间窗口**：入场、首轮爆发、长冷却、成长、永久叠层、复活周期会改变 30／60／180 秒结果。快速档不是标准档的等精度替代品，低频技能建议补长时实验。
- **玩家操作**：手动指定大招、预判施法、拉扯、卡位、切形态、重置攻击、主动卖建塔及最优瞬移节奏未完整实现。自动技能保留，但不能代表熟练玩家上限。
- **目标与地图**：只有固定数量、血量、抗性、速度和直线路径；没有多路、转角、极窄／极宽集群、特殊地形、元素免疫及完整 Boss 阶段。攻击范围的价值也受供靶位置限制。
- **站位分测**：远程模式只禁止主体相反普攻，保留技能和召唤物；移动场景可能接敌。它回答“此种站位下保留原生自动机制时有多强”，没有隔离纯近战／远程技能体系。
- **归因与控制**：复用弹丸、自定义脚本、特殊魅惑、传送、变羊、直接改血、驱散与反伤需逐个核对；现有控制折算、治疗与辅助收益不是完整机制价值模型。
- **场景权重**：攻坚内三场等权，对空单体／群体等权，综合权重为人为选择。不同地图和玩法可能需要不同权重，不能把当前权重视为专业共识。
- **成本与协同**：满级塔不等金币配平；固定友军无法覆盖减甲＋物理队、增伤＋高频塔、召唤物上限及光环叠加等组合。经济轴不能替代完整关卡预算实验。
- **样本数量**：3／5 种子不足以稳定估计稀有触发的尾部收益。多线程使用独立进程与独立随机状态，不会增加每对象种子数量。
- **失败附录**：`hero_isfet` 的原生升级冷却结构不兼容（两个模式各失败 55 轮）；`tower_stage_20_arborean_barrack` 缺少适配的插入条件（10 轮）；三种 `tower_stage_20_arborean_watchtower` 依赖专用关卡隧道实体（各 50 轮）；`tower_stage_38_dragon_wardens` 依赖关卡目标（50 轮）。这是本标准档的失败计数，后续批次以各自报告为准，不能给这些对象排低等级。
