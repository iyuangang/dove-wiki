# 页面状态与计算流程优化

本次落实优化清单第 1–4 项，以及对应的浏览器回归检查。设计沿用 Refactoring UI 的功能优先、清晰分组和既有字号/间距等级，保留绿色图鉴主题。

## 操作状态

由 App 创建并提供当前页面会话的工作区。计算目标、科技、辅助等级与条件、傀儡参数、随机种子、攻击记录页码，以及塔、英雄、敌人、更新页筛选、科技方案和双塔对比选择均在页面切换后保留；同时恢复各页滚动位置。视图仍正常卸载，弹窗事件与 ResizeObserver 会清理。

计算台新增“重置计算配置”，恢复完整默认配置。既有科技、辅助、模拟的局部重置入口仍可分别使用。工作区保存在内存中，刷新页面后恢复默认值；本批没有加入保存方案或分享链接。

## 百科到工具的入口

- 塔详情支持作为计算目标、启用该塔辅助，以及加入左侧或右侧对比；只修改用户选择的对象，保留其他配置。
- 辅助英雄详情支持启用该英雄的辅助效果，保留已有辅助及目标塔。
- 敌人详情按百科当前难度载入生命、双抗及飞行标记，保留攻击与辅助配置。无生命面板时禁用载入。
- 跳转后焦点进入相应选择框或配置区，并避开固定导航和手机结果速览。

## 输入与结果状态

数字字段统一提供稳定的可访问名称、错误描述及 aria-invalid。校验空值、非有限数字、上下界、数量字段的整数要求和伤害区间顺序。无效增益参数暂不展示增益结果，无效模拟参数暂不展示模拟结果与逐击记录，修正后自动恢复。

辅助卡显示实际参与状态及未参与原因。切换目标后，不适用的已选效果仍可取消。敌人面板明确区分待载入、已载入和已修改；更改敌人或难度不会自动覆盖用户编辑的傀儡参数。

本次未修改游戏快照、同步逻辑、增益公式、科技结算规则或伤害模拟公式。校验只控制输入是否可用于展示和计算。

## 弹窗键盘操作

塔、英雄和敌人详情采用同一焦点管理：打开后聚焦弹窗，Tab/Shift+Tab 保持在弹窗内，Esc 关闭，关闭后恢复打开按钮。失去连接的旧按钮不会被重新聚焦。
