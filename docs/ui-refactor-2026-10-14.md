# UI 优化记录

使用用户指定的 [Refactoring UI skill](https://github.com/LovroPodobnik/refactoring-ui-skill/blob/main/.claude/skills/ui-refactor/SKILL.md)，阅读 hierarchy、layout-spacing、typography、color 与 depth-and-polish 五份参考。只使用其设计文档，本次不安装全局技能。

## 先整理使用路径

辅助计算的布局草图：

```text
桌面：                                手机：
目标塔 / 科技配置  | 实时结果           目标塔 / 科技配置
辅助来源筛选      | 主要数值           滚动时保留结果速览
名称、收益、开关  | 应用效果           来源筛选 / 已启用
启用后配置参数    | 计算口径           启用后配置参数
按需展开规则      |                    按需展开规则
伤害演示                              伤害演示 / 完整结果
```

先解决辅助列表与参数的分组，再调整颜色和字体。过滤来源不会取消已选效果；启用后显示参数，效果说明通过原生 details 按需查看。基础数值、覆盖半径和持续时间保持可见。手机提供结果速览及完整结果入口，减少来回滚动。

## 设计约束

- 字号使用 12、14、16、18、20、24、30、36、48px 的等级；正文与表单以 14px 为基准，辅助文字至少 12px。
- 间距使用 4、8、12、16、24、32、48、64px 的等级；组间距大于组内距。
- 保留绿色图鉴的主题，统一 HSL 表面色、金色强调色和状态色。正文与辅助文字使用可读的对比度。
- 数值使用等宽数字并突出计算后结果；字段名称、来源 ID 与解释降低权重。解释不再依赖绝对定位挤在数值下面。
- 普通卡片依靠表面色和留白，弹窗使用更高的阴影层级；键盘焦点清楚，切换开关保持可点击区域。

## 验证

- 桌面 1280px、平板 768px、手机 390px 和 320px 检查八个主页面。修复 320px 更新页长敌人 ID 换行，以及 768px 双塔对比选择框的固有宽度溢出。
- 检查塔与英雄详情、辅助类型与搜索筛选、跨来源保留选中状态、键盘展开规则、手机结果速览与完整结果入口。跳转后焦点进入完整结果，标题位于速览下方。
- 原有 137 项测试通过，数据校验通过，使用 `/dove-wiki/` 基路径的生产构建通过。构建仍提示原有主脚本体积超过 500kB。
- 抽样计算正文与表面背景的对比度为 9.28:1，辅助来源文字为 6.94:1。
- 游戏快照、技能数值、同步工具和计算公式没有改动。
