# 数据同步与辅助计算（Dove 2.0.9.3）

核对安装版本：2.0.9.3，内容 5.6.12，提交 `731afe683e16e3adbfe162cf2b7452cc7bd2f867`。

- `all/difficulty.lua → patch_templates` 处理敌人生命、双抗、移速、金币与攻击数组。四项数组在难度 3 下读取第 4 项；数组直接选值，标量按游戏难度因子调整。提取器在独立副本上调用原函数，避免重复乘算或污染塔/英雄基础快照。
- `kr1/boss.lua` 中维兹南继承 `enemy_stage_218_veznan_illusion → boss`。金井使用普通敌人基类，但在首领模板文件中定义；原初共生体为小首领，作为已核实例外保留。`F_BOSS` 同时用于特殊免疫，因此不能单独决定展示分类。
- `kr1/game_scripts.lua → controller_mage_purge_field.update` 向 `tower.damage_factor` 加入 `0.14 + min(敌人数 × 0.01, 0.3)`。此增益与辅助伤害系数的增量相加。旧计算器将其乘在辅助系数前，导致同时启用时额外放大伤害。
- `kr1/upgrades.lua` 根据科技后弹丸模板伤害选择护甲撕裂档位，阈值严格大于 10/20/40；辅助增伤不改变这个预先选定的档位。奥术粉碎对 `ray_arcane` 强制使用普通档，其余以最高伤害是否达到 50 决定。
- `kr1/game_templates.lua` 和 `all/templates.lua` 定义放血概率、跳伤比例、持续时间、间隔与叠层上限；`kr1/game_scripts.lua → mod_blood_elves.insert` 读取预测伤害，`all/scripts.lua → mod_dps.update` 负责持续结算。规则值集中在人工审阅文件，UI 说明与模拟输入共用同一组值。

主快照格式为 2，计算规则格式为 1。`snapshot-manifest.json` 保存快照哈希、塔与英雄审阅来源、无效指纹清单。哈希统一规范化文本换行，兼容 Windows 检出与 Linux CI；人工指纹不会由同步工具更新。

同步使用独立暂存目录、互斥锁与恢复日志。正式资源替换前通过原始快照、规范化结构、审阅来源和 PNG 引用检查；逐文件替换避免 Windows 开发服务器对目录的监视锁，字节未变化的图片保留。替换出错恢复旧结果，进程中断后下次运行先恢复。`--check` 只生成检查报告，正式快照不变。英雄单独同步只替换英雄资源、主快照与清单。

验证涵盖安装游戏模板/难度提取、资源引用、失败回滚、中断恢复、跨平台哈希、独立审阅版本发布，以及增伤相加和严格阈值边界。浏览器核对敌人难度切换、预设载入及自定义攻击间隔。没有进行游戏内战斗逐帧验证；傀儡仍以单个目标、无免疫/护盾/专属脚本为口径。
