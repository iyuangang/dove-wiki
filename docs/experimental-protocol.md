# 独立实验 v1

在插件目录运行 `Run-Experiments.cmd`。生成的 `experiments.html` 可离线查看；天梯页下方“独立实验室”可在本机读取 `experiments.json`，不会上传文件。

四组实验分别回答：首段救场与持续机动是否不同；无反击耐久靶和有压力场景中友军收益如何；英雄在0.5、1、2倍敌人伤害下能坚持多久；相同金币上限实际建造多座同型满技能塔后表现如何。预算组计入完整建造、升级和技能成本，余款保留，采用固定阵位，最多12座。暂不支持雇佣塔及复杂地形。

实验保留自动技能与召唤物，不覆盖完整手动操作。无反击辅助组降低击杀与承伤的干扰；仍不能将两组差值解释为严格的纯辅助因果贡献。生存压力只改变敌人原生伤害倍率。每个实验保留版本、提交、档位、种子、条件与原始证据，失败显示为证据不完整。

本实验采用独立协议 `dove-lab-experiments-v1`，不生成正式分数或等级，不可导入正式基准，不改变现有天梯。先收集玩家反馈，再决定未来正式协议是否采纳新场景；若采纳，需要更新协议并完整重测。
