# Dove 2.0.8.9 机制复核

复核日期：2026-10-08。游戏提交：`45073448b340682d893dec553d495153108f186e`，内容版本 `5.6.12`。

依据用户的新安装目录中实际加载的 Lua 模板、攻击脚本、伤害系统及编译动画表核对。原快照有 123 条塔机制、114 条英雄机制因指纹变化而待复核。比对旧安装的函数与模板差异，再检查影响结论的当前分支；没有用技能名称或本地化简介替代攻击逻辑。同步本身仍不更新审阅指纹。

## 原有条目

- 少林寺：新版实际读取 `kr1/data/game_animations.bin`。解码确认拳/踢入场各 9 帧、退场各 8 帧、空中退场 8 帧；地面单僧约 17/30 秒，三僧集中约 0.7 秒。保留可眩晕、非 Boss、未被士兵阻挡三个条件，以及目标分配衰减和金币标记阈值。编译表使用逐字节指纹与准确动画键校验，不伪造源码行号。
- 熔炼炉：`tower_melting_furnace.update` 直接等待当前 `hit_times`。攻速通过 `SU.change_fps` 缩放相关字段，旧说明中的“再乘冷却系数”已删除。
- 三连火炮：`tower_tricannon.update` 在过热等级大于 0 时始终给普攻和轰炸弹附着焦土。模板残留的过热冷却与持续时间不再控制附着。焦土半径 40、持续 3 秒；燃烧每 0.5 秒结算 5 × 等级点真实伤害，可刷新。
- 连锁、储弹、多目标分配、减甲/削魔抗、诅咒、特殊闪避、刺客保命及伤害类型结算：原有结论对应的分支仍成立。新版集结点处理调整与动画/前摇修正没有改变这些条目中的目标数、倍率、状态条件和伤害类型。
- 英雄：旧英雄基础导航与移动形态参数保持一致；对变化的专属移动脚本和通用调动流程核对，标记管理改为逐位引用计数，没有改变已描述的距离、技能解锁、形态限制。保留变形赶路与常驻飞行的区别。新增浚湃被动：生命严格低于 80% 时输出倍率乘 1.5，恢复到阈值时撤销，不连续累乘。
