# Dove 2.1.0.6 开发预览版同步

游戏提交：`4de3c0b894526ea8ad1e58e1ddd3ecee072bee15`，分支 `dev`。百科同步 109 座常规塔、91 位英雄、354 个敌人百科槽位（350 个不同敌人）及四套共144项科技。页面按数据来源显示“开发预览版”，旧快速测评保留原版本标记。

标准测评来自 `standard_20261102_103100_400`。91 位英雄分别测试近战、远程，97 座最终阶塔和12座过渡塔，共291条正式结果、16,915轮正式样本；含支持的关卡专属对象共18,130轮，全部成功。不支持的关卡机关继续保留说明并排除评级。快速档不替换。

## 新版提取方式

- 英雄名单来自 `kr1/heroes/registry.lua` 的声明，离线百科导出明确请求全部英雄，再通过原生接口加载对应模板；不再依赖旧 `hero_data` 或已加载实体的偶然子集。
- 头像和缩略图使用声明中的真实资源键，能力按 `room_special_order` 保序。445条能力说明使用游戏原生表达式格式化函数求值，未求值的代码不进入玩家文案。缺少旧 `hero_room_special.lua` 不再导致同步失败。
- 新版科技使用字符串编号的 `upgrades.list` 和各方案的 `techs`；导出按编号排序，兼容旧数字数组。
- 基础参数来源定位到实际英雄模块及行号。读取新模块用于定位不等于完成机制审阅：没有更新历史审阅指纹，变化的专属机制继续待核实。
- 游戏图片、天梯图和逐轮证据保持在校验固定的独立资源包中，不加入Git。原始测评与个人基准不修改。

后续同时安装多个游戏版本时，使用 `Update-And-Publish.cmd --game-dir "目标版本的KingdomRushDove目录" --run-directory "完整批次目录"` 明确指定来源。同步器会在数据校验通过后替换结果；源码适配仍按 feature/fix → dev → main 的 PR 流程发布。
